Built for a point-of-care team, not a data centre

Runs from an encrypted USB drive

Own Python runtime, no installation, no admin rights, BitLocker To Go on the whole drive.

Offline by enforcement

All three servers bind to the local machine only and a runtime guard blocks and logs any outbound attempt.

Encrypted history

Named staff error history is AES-encrypted with a password that is never stored; trends and recurring flags build month by month.

Licensed per PC

Licences are issued centrally, bound to the motherboard, and expire with the 12-month QIS review cycle.

Per-ward reports for large sites

Twenty-four hospitals get one report per ward plus a site overview; every HHS gets an area summary.

Dormant analysers handled

Four months with no cartridges, simulators or ceramics and a unit is left out of the reports and listed for review.
